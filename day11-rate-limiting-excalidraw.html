🪣 Token Bucket Algorithm
Tokens added
at a fixed rate
Bucket Capacity
= Burst Limit
  • 1 Refill tokens
    (at fixed rate)
  • 2 Each request
    consumes 1 token
  • 3 If token available ➔
    Allow request ✔
  • 4 If no token ➔
    Throttle / 429 ❌
Example
Rate : 5 tokens/sec
(refill rate)
Burst : 20 tokens
(bucket capacity)
🔘 1 request = 1 token

⚖️ Rate Limiting vs Throttling
Rate Limiting
✔ Controls how many requests are allowed.
✔ Defines the limit.
✔ e.g., 100 requests/min
Throttling
✔ Slows down or rejects excess traffic.
✔ Enforces the limit.
✔ e.g., 429 Too Many Requests
